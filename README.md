# Mosaic Fitness Center — Homepage Redesign Demo

A premium, conversion-focused homepage redesign for **Mosaic Fitness Center** — a coach-led functional fitness facility in Fairfax, Virginia.

- **Single file:** `index.html` (no build step; only external dependency is Google Fonts).
- **Brand-accurate:** the dark theme + **hot-pink `#f0327d`** and **cyan `#2ea8e6`** accents are sampled directly from Mosaic's real logo. Their actual logo is used in the nav/footer.
- **Real media:** all photos and the hero video in `/assets` are Mosaic's own, pulled from mosaicfitnesscenter.com.
- **Real content only:** copy, programs, hours, address, and phone come from the live site. No fabricated testimonials, reviews, statistics, or certifications.
