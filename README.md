# Mosaic Fitness Center — Homepage Redesign Demo

A premium, conversion-focused homepage redesign concept for **Mosaic Fitness Center** — a coach-led functional fitness facility in Fairfax, Virginia.

- **Live demo:** enabled via GitHub Pages
- **Single file:** `index.html` (no build step, no dependencies beyond Google Fonts)
- **Real content only:** all copy, programs, hours, address, and phone are pulled from [mosaicfitnesscenter.com](https://mosaicfitnesscenter.com/). No fabricated testimonials, reviews, statistics, or certifications.
